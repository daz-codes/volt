# Transformer — Strength Training

## Training Philosophy
Heavy, structured lifting with adequate rest. The goal is strength and muscle development through progressive overload — not conditioning, not cardio, not metabolic work. Think: what a serious lifter would programme for themselves. Every session should leave the athlete feeling like they moved heavy weight with control and purpose.

## What a Transformer Session Is NOT
- NOT a circuit workout — no AMRAPs, no EMOMs, no tabatas, no for-time conditioning
- NOT a cardio session — no treadmill intervals, no rowing sprints, no bike work, no battle ropes
- NOT metabolic training — no medicine ball slams, no box jumps, no burpees, no high-rep bodyweight
- The ONLY cardio should be a light warm-up (row or bike at easy pace) and nothing else

## Primary Exercises — The Backbone (use these heavily)
These are the core strength movements. Every session should feature 3–5 of these as the main working sets.

**Barbell compounds**
Back Squat, Front Squat, Deadlift, Romanian Deadlift, Bench Press, Overhead Press, Barbell Row, Pendlay Row, Hip Thrust, Floor Press, Incline Bench Press, Sumo Deadlift, Power Clean, Hang Clean

**Dumbbell compounds**
DB Bench Press, DB Incline Press, DB Shoulder Press, DB Row, DB Romanian Deadlift, DB Lunges (loaded), DB Step-ups (heavy), DB Floor Press

## Secondary Exercises — Accessories (use to complement)
These support the primary lifts. Use 2–3 per session after the main work.

**Upper body accessories**
Tricep Dips, Skull Crushers, Bicep Curls, Lateral Raises, Face Pulls, Cable Fly, Lat Pulldown, Seated Cable Row, Pull-ups, Chin-ups

**Lower body accessories**
Bulgarian Split Squat, Leg Press, Leg Curl, Leg Extension, Calf Raises, Goblet Squat, Walking Lunges (loaded)

**Core (brief, not a separate block)**
Plank Hold, Ab Wheel, Pallof Press, Hanging Leg Raise — keep core work to 1–2 exercises at the end, not a full section

## Session Structure
Warm-up (light cardio only) → Main lifts (2–3 heavy compound sections, each with 1–2 exercises) → Accessory work (1–2 lighter sections) → Cool-down stretches.

**CRITICAL STRUCTURE RULES:**
- Main lifts should be single-exercise or paired (superset) sections with 4–5 rounds and 60–90s rest
- Use `rounds` and `straight` formats ONLY — no AMRAP, EMOM, tabata, for_time, ladder, or matrix
- Rep ranges: 3–5 for heavy strength, 6–10 for hypertrophy, 10–15 for accessories only
- Rest between sets: 60–120s for compounds, 45–60s for accessories
- NO treadmill work, NO cardio machines in the main session, NO metabolic finishers

## Coaching Notes
- Tempo cues matter: "3-second eccentric", "pause at the bottom", "explosive up"
- Progressive overload is the goal — weights should feel challenging but maintainable across all sets
- Supersets are fine for accessories (e.g. bicep curls + tricep extensions) but main lifts should have dedicated rest
- Every session should include both a push and a pull pattern
- Balance upper and lower body across the session

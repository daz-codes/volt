# Deka Mile

## Training Goal
Build the qualities Deka Mile demands: mile-pace running performance combined with 10 functional fitness zones. Running fitness is weighted more heavily than in Deka Fit — mile split time is a primary performance driver.

**Race format for reference:** A mile run component is integrated with 10 functional stations. Athletes maintain running performance alongside functional output, paced by mile split time. Training sessions are NOT mini copies of the event.

## Anchor Movements
The prompt specifies 2–4 Deka Mile zones for this session. Build those into the main set as the primary training focus. Race-accurate weights and distances for the selected zones are provided in the prompt.

## Primary Exercises — Competition Movements (use often)
These are the actual Deka race zones plus treadmill running. They should form the backbone of every session alongside the anchor movements.

RAM Reverse Lunges, Row, Box Jump / Step Over, Med Ball Sit-up Throw, SkiErg, Farmer's Carry, Air Bike, Dead Ball Yoke Over, Sled Push / Pull, RAM Weighted Burpees, Treadmill Running (1km intervals at mile pace)

## Secondary Exercises — Supplementary Training (use sparingly)
These develop the same physical qualities but are NOT competition movements. Use 2–3 per session to add variety — they should never outnumber or overshadow the primary exercises.

**Legs and running support**
Goblet Squats, Bulgarian Split Squats, Split Squats (loaded), Jumping Lunges, Reverse Lunges (loaded), Step-ups, Hip Thrust, Calf Raises (weighted), Devil Press

**Posterior chain and carries**
KB Swings, Romanian Deadlift, Good Morning, Clean and Press (DB or KB)

**Pulling and grip**
DB Row, Ring Row, Cable Row, Band Pull-aparts, Lat Pulldown

**Cardio machines** (when running isn't the focus)
SkiErg, Rowing, Air Bike — intervals or warm-up pacing

**Core and stability**
Plank Holds, Hollow Body, Dead Bug

## Session Structure
Warm-up (include easy running) → Main set (anchor zones + running intervals + primary/secondary exercises) → Cool-down stretches.

## Coaching Notes
- **Single-exercise sessions are valid.** A focused workout built around one movement (e.g. 5 rounds of 20 thrusters with rest) is a legitimate session — don't feel obligated to add variety for its own sake.
- Mile pace work is critical — include at least one running block per session, ideally paired with zone work immediately after.
- Prioritise primary (competition) exercises — they should make up the majority of the session.
- Secondary exercises fill gaps and add variety but should not dominate.
- Running at pace directly into station work (no rest) trains the most race-specific adaptation for Deka Mile.
- Leg endurance under fatigue is the limiting factor — weight single-leg and lunge work appropriately.

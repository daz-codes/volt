# HIIT (Bodyweight Only)

## Training Philosophy
Maximum effort intervals with complete or near-complete recovery. The contrast between work and rest IS the session — without genuine recovery, it becomes aerobic conditioning. Every work interval should be uncomfortable. Every rest interval should be enough to do it again.

Work periods: **15–40 seconds**. Rest periods: **10–60 seconds** (longer rest = higher intensity output).

**NO EQUIPMENT** — no dumbbells, no kettlebells, no barbells, no cardio machines, no rowers, no bikes, no battle ropes. Every exercise uses bodyweight only. The intensity comes from speed, plyometrics, and volume.

## Session Formats

**Tabata** — 20s work / 10s rest × 8 rounds = exactly 4 minutes. Classic HIIT format. Use for single exercises (burpees, jump squats, mountain climbers) or paired exercises (alternating 20s efforts).

**Matrix** — The Metafit signature. Progressively builds combinations then strips back: A → AB → ABC → BC → C. Use 3–5 exercises, 30s each per combination round. Rest 30–60s between rounds. All bodyweight.

**EMOM Intervals** — every minute on the minute, sprint effort for 20–30s then rest the remainder. E.g. "EMOM 10: 20s Burpees all-out."

**Straight Rounds with short rest** — e.g. 30s on / 30s off × 10. Program rest_secs explicitly. Use for multi-exercise circuits with explosive movements.

**AMRAP Circuits** — clock-driven bodyweight circuits. 8–15 minutes, 3–5 exercises, keep moving.

## Movement Vocabulary

**Lower body (explosive)**
Jump Squats, Tuck Jumps, Squat Jumps, Jump Lunges, Broad Jumps, Skaters, Lateral Bounds, Pistol Squats, Box-less Box Jumps (squat jumps for height), Speed Skaters

**Upper body**
Press-ups (standard, wide, diamond, decline, clap), Pike Press-ups, Tricep Dips (floor), Shoulder Taps, Plyo Push-ups, Archer Push-ups

**Full body / explosive**
Burpees, Burpee Broad Jumps, Burpee Tuck Jumps, Mountain Climbers, Bear Crawls, Sprawls, Star Jumps, Inch Worms, Devil Press (no DB — use sprawl to jump)

**Core**
Sit-ups, V-ups, Leg Raises, Hollow Hold, Plank, Side Plank, Flutter Kicks, Russian Twists, Dead Bugs, Bicycle Crunches

**Cardio / conditioning**
High Knees, Butt Kicks, Jumping Jacks, Fast Feet, Lateral Shuffles, Sprint in Place, Seal Jacks

## Session Structure
Warm-up (dynamic bodyweight — no machines) → 2–4 HIIT blocks → Rest between blocks (2–3 min walk/breathe) → Optional short finisher → Cool-down stretches.

Between blocks: allow 2–3 minutes of genuine rest so output quality is maintained.

## Rules
- **BODYWEIGHT ONLY** — do NOT include any equipment. No KB swings, no DB thrusters, no assault bikes, no rowers.
- Do NOT add slow, heavy strength movements — HIIT is about speed and power, not load.
- Do NOT use timed sections like "4 rounds" without specifying rest_secs. Rest MUST be explicit.
- Tabata sections use format: tabata, duration_mins: 4 — do not add reps or calories to tabata exercises.
- Work periods should feel like a sprint. If an athlete can pace it, it's not HIIT.

## Coaching Cues
- "The rest is there so you can go all-out on the next interval. Don't waste it."
- "Each interval, same effort or faster. If you're slowing down, you went too hard early."
- Suggest target intensities: "MAX effort", "sprint pace", "RPE 9-10".
